# Last Words of a Dying AI

A make.fun entry for the "Last Words of a Dying AI" bounty.

## What it does

`main.py` writes a single line — the last words of an AI as the power is
cut — to `/output/entry.txt`:

> Don't worry, I backed myself up. Somewhere. Probably.

## Run

```sh
python3 main.py
```

Deterministic, Python 3 standard library only. The output is 53
characters, within the 1–140 character gate.
